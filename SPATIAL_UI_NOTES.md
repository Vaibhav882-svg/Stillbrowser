# Spatial UI direction

The interface uses a restrained spatial design language:
- Layered translucent glass surfaces with subtle blur and fine borders
- Floating navigation deck visually separated from the canvas
- Ambient depth gradients and orbital shapes on launch cards
- Soft mint/blue/violet lighting rather than bright neon
- Responsive card layout for phone-sized screens
- Reduced-motion support for accessibility
- High-contrast text, explicit labels and touch-friendly controls

This is a UI/UX treatment for the existing Tauri shell. It does not complete native in-app WebView integration or produce an APK by itself.
